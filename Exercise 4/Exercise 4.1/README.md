# Exercise 4.1
This exercise demonstrates the use of SVG shapes to create a house and garden.

## Completed Tasks

- Created a house and garden using different SVG shapes.
- Annotated the SVG coordinate system.
- Customised the SVG using different colours and strokes.
- Added extra objects such as flowers, smoke and a garden path.
- Used the `<g>` element to group the two windows.
- Used `transform` and `translate` to position the windows.
